# Screenshot-based promotional set

Eight compositions made with built-in image_gen using the existing gameplay captures, the owner's layout reference, the approved gold trophy logo and the About section coach reference.

- `masters/`: unchanged generated masters.
- `promotional-1920x1080/`: full-size promotional PNG exports.
- `about-800x450/`: smaller About section PNG exports.
- `index.html`: preview all eight.
- `prompts.json`: generation prompts.
- `sources.json`: source master paths.
- `manifest.json`: dimension validation and hashes.

These are generated marketing composites. Small interface details and text can differ from the game. They are for About This Game and marketing, not unaltered gameplay screenshots. Keep the authentic captures in `../gameplay-gallery-2026-09-17` for Screenshot Assets. Nothing in this pack has been uploaded.

The owner's original gold trophy logo is preserved unchanged in `../approved-brand/gold-trophy-logo-original.png`. Generated compositions reference that design but do not guarantee a pixel-exact reproduction. The executable icon and existing Steam assets have not been replaced by this task.

Local resizing was explicitly authorized by the owner earlier in this conversation. Originals and earlier artwork remain preserved.
