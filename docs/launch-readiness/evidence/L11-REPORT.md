# L11 — controlled perception and collision-tested encounters

13 September 2026. **Implementation pass; launch acceptance remains partial.** Dependencies L04/L10, manual Mirage geometry review, packaged Windows testing, the real Steam App ID and content clearance remain open.

## Result

Simulation lab now runs a bounded two-player encounter. Each player acquires visible body samples inside their field of view, waits through a continuous reaction window, turns their aim, fires a resolved ray and takes damage from actual hits. There is no selected winner input. Elimination or the time limit determines the result. The existing career match generator is unchanged: its spatial replacement belongs to the later integration package.

Open **Map Studio → Simulation lab → Encounter lab**. Choose a Mirage example and **Open encounter example**, then **Run encounter**. Opening an example downloads the current lab test as a backup and uses the existing edit/Undo flow. Choose **Player A knowledge**, **Player B knowledge**, or **World truth · observer**. Play, pause, step or scrub the encounter; the timeline explains sight, reaction, reload, shot, obstruction, miss, damage and death events. Only the observer view displays both actors' exact state. A player view shows that player's own events and observed or remembered target point, with an expanding uncertainty ring after loss of contact.

Five versioned Mirage examples cover clear sight, opaque geometry, both players facing away, A reloading and a simultaneous trade. Their positions are selected from supported, clear navigation surfaces against the pinned 2000908 mesh. They are controlled tests, not tactical recommendations or certified map locations. Each example has its own portable `.lab.json` file and checksum in `public/map-studio/encounters/l11/index.json`.

## Rules and information boundaries

- The engine is pure, bounded to two actors and 1–20 seconds at 64 ticks/s. Each actor has an independently seeded RNG stream. It does not access React, storage, wall clocks or global randomness.
- World truth enters the perception boundary and physical hit resolution. Aim and firing decisions consume only the actor's own observed knowledge. Missing visibility resets reaction readiness, freezes the last observed point, decreases confidence and expands uncertainty at 220 world units/s. Memory expires 128 ticks after the last observation. This policy does not fire blind or turn toward an unseen live coordinate.
- Visibility uses a conical FOV, eye height and four body samples against two-sided static geometry. It does not infer visibility from a 2D radar line. Low cover can expose a head while still stopping a torso-level shot.
- The tick senses both actors, schedules both eligible shots, then applies damage. Lethal shots scheduled in the same tick can trade; array iteration does not cancel the second shot. Death stops further movement and firing.
- Optional A approach movement is a deliberately scripted scenario route generated by the existing navigator and movement runner, with floor support, body sweeps and a stand-off before reaching B. It is not an autonomous decision based on knowledge. Both actors otherwise hold position. No moving-team coordination is claimed.
- Opaque geometry at or before a hit volume stops the bullet. No penetration rule is enabled. Intervening floors/ceilings use the same 3D ray test.

## Provisional model and units

`lab-rifle-v1` is original lab tuning, not imported or calibrated CS2 weapon data. Positions, ranges and hit volumes use the existing map world units. View angles and spread use degrees; facing turns by up to 300 degrees/s on each axis. Reaction milliseconds are rounded up to complete ticks. Standing height is 72, crouching height 54, and eye height is body height minus eight.

The target uses a radius-six head sphere and an axis-aligned torso box (24 units wide, feet+2 through body height−16). These are approximate hit volumes, not the portrait or a character mesh. Base damage is 34, head multiplier four, range 4,096, with a 0.98 multiplier per 500 units. Eligible armor absorbs up to 35% of raw damage while armor remains; head armor requires a helmet. Damage and armor consumption round up explicitly.

A full magazine holds 30 rounds with 60 initial reserve. Shots are seven ticks apart; each three-shot burst adds a fourteen-tick pause. Empty magazines reload for 144 ticks (2.25 seconds). Ammo moves from reserve exactly once at reload completion. Recoil accumulates per shot and recovers over time; stance, authored aim error and actual movement speed affect spread. Reloading and reacting may overlap, but both requirements must finish before a shot.

## Implementation and persistence

- `engine/spatial/encounter.ts`: bounded settings validation, knowledge, aim, events, hit volumes, shot obstruction and damage.
- `engine/spatial/lab-encounter.ts`: shared lab execution using the existing reference, authored bound geometry and optional movement route.
- `engine/spatial/spatial-lab.worker.ts`: validated, correlated encounter request/response on the actual spatial worker.
- `components/maps/EncounterLab.tsx` and its CSS module: setup, knowledge inspector, 2D replay and event timeline. `SpatialLab.tsx` mounts it and provides the shortcut.
- `lib/spatial-lab-project.ts`: whitelisted optional encounter settings in the existing independent lab format. Older files retain their previous behavior; new settings persist through Save/Open test and local autosave.
- `scripts/launch/build-l11-fixtures.ts`, `l11-browser.ts` and the existing native probe produce repeatable, source-bound evidence.

No career save schema migration is required. Export replay includes the exact input project, reference identity and full result for diagnostics; it is not a save-game file or an additional replay-import flow. Save test remains the editable input export. Older application versions can discard the optional encounter settings if they re-export a test, so keep the new export before rollback. User Map Studio drafts and source uploads remain separate and unchanged.

## Remaining acceptance and next work

The controlled encounter is a foundation for L11, not proof of perfect shooting or a completed live match engine. Remaining evidence includes measured weapon/movement/reaction calibration, reviewed Mirage wall heights and CT/A/B ground bounds, vertical transition checks, broader maps and packaged target-machine acceptance. The static reference is approximate and version-pinned; the existing content gate remains held.

L12 is the next development package: utility trajectories and effects, smoke visibility, flash exposure, HE/fire cover and reviewed dynamic geometry. Team communication, tactical decisions and coordination belong to L13. L14 connects authoritative spatial events to live-match results and the radar. No utility, hearing, wall penetration, team communication or autonomous combat path selection was added in this pass.
