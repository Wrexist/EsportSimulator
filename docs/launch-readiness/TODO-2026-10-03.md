3. **Lint:** 143 warnings → 0, no behavior changes; none of the 5 hook warnings were real stale-closure bugs.

Legacy `config.json` is imported once (copy-if-absent, read-back verified, marker last) and never written again; an unreadable `config.json` no longer blocks startup or per-file careers. Window settings moved to `settings.json`. No Steamworks change needed (manual Cloud API, file names unchanged). Packaged upgrade from a real pre-change install still to be verified.
